# 🗄️ DevShelf — сайт-витрина портфолио с подтверждением авторства

> **Полная характеристика проекта для продажи.** Продающийся сайт: merugan.is-a.dev (работает 24/7, можно показать покупателю вживую).

---

## 1. Что это такое — простыми словами

**DevShelf** — платформа, где программисты, дизайнеры, OSINT-специалисты, кейсисты и создатели ботов публикуют свои работы и **доказывают, что это их работа**.

Главная фишка и причина, почему такой сайт вообще нужен: в интернете тысячи «портфолио», где кто угодно прикладывает чужие скриншоты. DevShelf решает это системой **автоматического подтверждения авторства**: каждая работа получает уникальный код `DEV-VERIFY:xxxxx`, автор вставляет его в README своего проекта, сайт сам проверяет код по ссылке и ставит плашку **«Авторство подтверждено»**. Плюс ручная проверка админом для нестандартных случаев.

Это не «ещё один Behance». Это **инструмент доверия**: заказчик приходит не смотреть картинки, а находить исполнителей с доказанными работами и честными оценками.

## 2. Полный список функций (всё работает прямо сейчас)

### 👤 Аккаунты и профили
- Регистрация двумя путями: **email с 6-значным кодом подтверждения** (письма через Resend) или **Google OAuth** в один клик.
- Юзернейм выбирается один раз и закрепляется навсегда — профиль живёт по адресу `/u/юзернейм`.
- Публичный **цифровой ID** (8 цифр) у каждого пользователя — выдаётся автоматически, навсегда. По нему можно найти человека, даже если он сменит имя. У создателя сервиса — ID `1` и бейдж **👑 «Создатель»**.
- Профиль: имя, аватар, био, **8 пунктов биографии** (специализация, опыт, образование, город, языки, занятость, достижения, факт), до 5 контактов (Telegram, GitHub и т.д.), стаж на сервисе, роли.
- **12 профессиональных ролей** — до 3 на аккаунт.

### 🗂️ Работы и верификация
- **11 типов работ**: сайт, веб-приложение, Telegram-бот, мобильное приложение, OSINT-кейс, раскрытие кейса, дизайн, дизайн-проект, архитектура, скрипт, свой вариант.
- Структурированное описание: процесс «как сделано», команда, стек, перспектива + до 3 ссылок.
- Автопроверка авторства по токену `DEV-VERIFY` + ручная проверка админом.
- Лимиты: **Free — до 5 работ, Pro — без лимита**.

### ⭐ Честные оценки
- Отзывы 1–5 звёзд; оценка ниже 4 звёзд требует обоснования от 30 символов — никаких «плохо» без аргументов.
- Один отзыв на человека, дубли и самооценки заблокированы.
- Владелец работы может **оспорить** несправедливый отзыв — спор уходит админу.

### 🔍 Поиск и витрины
- **Раздел «Люди»**: список всех участников, поиск по имени/юзернейму/ID, фильтры по ролям и специализациям (клик по специализации — показать людей с ней), пагинация.
- **Витрина работ**: поиск по названию/описанию/стеку, фильтр по типу.
- **Живая полка на главной** — свежие работы с «дышащими» счётчиками сообщества.
- Витрина наполняется демонстрационным сообществом (сотни живых профилей и работ), чтобы сайт с первого дня выглядел действующим — контент генерируется автоматически, покупателю не нужно ничего придумывать.

### 💬 Сервисные тикеты
- Полноценная **переписка пользователь ↔ админ** в каждом тикете (не одно сообщение, а живой чат), бейджи непрочитанных, статусы, счетчики в навбаре.

### 💳 Монетизация
- Тариф **Pro — 499 ₽/мес**: безлимит работ, Pro-бейдж в профиле.
- Оплата: карта РФ/СБП/крипта — реквизиты выдаёт админ, скрин оплаты уходит в **админ-модерацию** (кнопка «Оплатить Pro» → заявка → админ подтверждает → Pro активен). Плюс **промокоды** — альтернативный канал выдачи подписки.
- Все административные инструменты уже встроены.

### 🛠️ Админка (7 вкладок)
1. **Портфолио** — модерация работ, подтверждение авторства вручную.
2. **Пользователи** — просмотр, поиск по логину/@юзернейму/email/**ID**, колонка ID, выдача/снятие ролей.
3. **Модерация** — споры по отзывам, жалобы.
4. **Тикеты** — чат поддержки с пользователями.
5. **Юзернеймы** — заявки на смену юзернейма.
6. **Оплаты** — заявки на Pro: скрин перевода, подтверждение/отклонение одним кликом.
7. **Промокоды** — генерация промокодов на Pro.

## 3. Технологии и инфраструктура (полная характеристика)

| Компонент | Что используется | Стоимость |
|---|---|---|
| **Фреймворк** | Next.js 16 (App Router) + React 19 + TypeScript | бесплатно |
| **Вёрстка** | Tailwind CSS 4 | бесплатно |
| **База данных** | PostgreSQL на **Neon** (облачный serverless-Postgres) + автоматический фолбэк на JSON-файлы — сайт работает даже если БД недоступна | бесплатно (free tier) |
| **Хостинг** | **Vercel** — автодеплой из GitHub: push в репозиторий → сайт обновляется сам за ~90 секунд | бесплатно (Hobby) |
| **Домен** | **merugan.is-a.dev** — бесплатный поддомен сервиса is-a.dev; при желании легко подключить свой домен (.com/.ru/.dev) | бесплатно / ~200–900 ₽/год за свой |
| **Почта** | Resend — коды подтверждения и уведомления | бесплатно (3 000 писем/мес) |
| **OAuth** | Google Cloud (бесплатная квота) | бесплатно |
| **SSL/HTTPS** | автоматом от Vercel + HSTS | бесплатно |

**Объём кодовой базы:** ~10 800 строк собственного кода, **22 страницы**, **33 API-эндпоинта**.

**Безопасность:** security-заголовки (защита от кликджекинга, MIME-sniffing, HSTS), rate-limit на вход/регистрацию/отзывы, хеширование паролей, серверные проверки прав на каждом эндпоинте, сессии в httpOnly-куках.

**SEO готово:** метаданные, sitemap.xml, robots.txt, manifest, OG-разметка — сайт индексируется поисковиками «из коробки».

**Развёртывание у нового владельца — 15 минут:**
1. Форкнуть репозиторий → подключить к своему Vercel.
2. Создать бесплатную БД на Neon → вставить `DATABASE_URL`.
3. Вставить ключи Resend и Google OAuth.
4. Задать свой `ADMIN_PASSWORD`. Всё — миграции создают таблицы сами при первом запуске.

Всё, что нужно передать покупателю: репозиторий GitHub + 5 переменных окружения. Никакого сервера, никакого SSH, ничего настраивать руками не надо.

## 4. Почему стоит купить именно этот сайт

1. **Он уже работает.** Покупатель получает не «исходники на promise», а действующий сайт с доменом, БД, живыми пользователями-демо и наполненной витриной. Можно открыть merugan.is-a.dev и пощупать всё: регистрацию, верификацию, оценки, тикеты, оплату.
2. **Ниша с реальным спросом.** Фриланс-площадки берут комиссию, а исполнителям нужно место, где их авторство подтверждено и видно заказчикам. Тема подтверждения авторства (особенно OSINT-кейсы и боты) — слабо занята в рунете.
3. **Монетизация уже встроена** — не надо «придумывать, как зарабатывать»: тариф Pro с оплатой по реквизитам, модерация оплат, промокоды. Покупателю остаётся только принимать деньги.
4. **Ноль вложений.** Весь стек (Vercel + Neon + Resend + is-a.dev) — бесплатные тарифы. Хостинг не съедает ни рубля, пока трафик до сотен тысяч визитов в месяц. Единственная возможная трата — свой домен за 200–900 ₽/год, и то по желанию.
5. **Современный и поддерживаемый стек.** Next.js 16 + React 19 + Tailwind 4 — не legacy: любой разработчик (или сам покупатель с ИИ-ассистентом) сможет развивать проект. Код типизирован, структура чистая, 22 страницы и 33 API задокументированы прямо в коде.
6. **Админка закрывает все операции** — модерация, оплаты, поддержка, промокоды. Управлять сайтом можно с телефона, без доступов к базе.
7. **Демонстрационное сообщество в комплекте.** Сайт выглядит живым с первого дня: профили с биографиями, работы с рейтингами, активная витрина. Новому владельцу не нужно месяц набивать контент.
8. **Автономность.** Фолбэк на файловое хранилище: даже при сбое БД сайт продолжает работать. Деплой — это git push, откат — это откат коммита.
